# B HJB subsolution criterion

## 1. 化为最优控制（作者级）

记号：Λ₀ = 37.7，c = 3√3π/2，修正 Prüfer 角，t = √Λ₀·y，ℓᵢ = √Λ₀·cᵢ，θᵢ′ = 1 − π²sin²θᵢ/ℓᵢ²，θᵢ(0) = π/2（Neumann 端）。
- 半直线化与正则化同 V-cert §1.1–1.2：偶剖面的 μ 等于半直线 Neumann 谱底；若 V_∞(W,ε) < Λ₀，可取 c = c₁ + c₂，截断到 [0,X] 并令 cᵢ ← cᵢ + ε′，则两个 Prüfer 角都在 t ≤ √Λ₀X 内到达 π，质量 ≤ 1/2 + 2ε′X，超出量 ≤ ε + 2ε′X。
- 物理量：质量 = (1/Λ₀)∫(ℓ₁+ℓ₂)dt，超出量 = (1/Λ₀)∫(ℓ₁+ℓ₂−W̃)₊dt，W̃ = √Λ₀W。

**松弛质量。** Uᵢ = 1 + cosθᵢ（单角自由值 c·Uᵢ），σ(t) := (Λ₀/c)(质量预算 − 已用质量) − U₁ − U₂。
- σ(0) = σ₀ + O(ε′)，σ₀ = Λ₀/(2c) − 2 = 0.30940。
- σ′ = −(1/c)[L − cΣXᵢθᵢ′] ≤ 0，因为单角不等式 ℓᵢ ≥ cXᵢθᵢ′（bbM 第 1 步）。
- 最终 σ = (Λ₀/c)(预算 − 总质量) ≥ 0。所以可行轨道始终在 σ ∈ [0, σ₀ + O(ε′)] 内，不需要障碍函数。

## 2. 次解判据（作者级）

令 E = γ·w(U₁, U₂, σ)，γ = 2c/Λ₀；梯度 (q₁, q₂, −k)，Pᵢ := qᵢ + k，ℓᵢ = √3π·mᵢ，ω := W̃/(√3π)。

**命题。** 若 P1 函数 w（Kuhn 四面体，[0,2]² × [0, σ_top]）在每个闭四面体上满足
- (G) k ≥ 0，P₁, P₂ ≥ 0；
- (H) 对格子盒内一切 (X₁, X₂)：3(P₁X₁ + P₂X₂) ≤ Ψ_k(P₁^{1/3}X₁ + P₂^{1/3}X₂)；

并且面上 w(0, ·, ·) ≤ 0、w(·, 0, ·) ≤ 0，σ_top > σ₀，那么每个可行剖面对的超出量 ≥ γ·w(1, 1, σ_top)。

其中
- Ψ_k(A) = 3k^{2/3}A，当 A ≤ k^{1/3}ω；
- Ψ_k(A) = 2kω + A³/ω²，当 k^{1/3}ω ≤ A ≤ (k+½)^{1/3}ω；
- Ψ_k(A) = 3(k+½)^{2/3}A − ω，当 A ≥ (k+½)^{1/3}ω。
Ψ_k 是 C¹ 凸增函数，对 k、A 单调增，对 ω 单调减。

推导：
- dw/dt = −ΣPᵢXᵢθᵢ′ + (k/c)L。要求 d(γw)/dt ≥ −(1/Λ₀)(L − W̃)₊，换成 m 变量即
  ∀m：ΣPᵢ(3Xᵢ − Xᵢ³/mᵢ²) ≤ 2kM + (M − ω)₊，M = m₁ + m₂。
- 固定 M 时，按 mᵢ ∝ Pᵢ^{1/3}Xᵢ 分配得 inf = A³/M²；再对 M 取 inf，分三段算出 Ψ_k。
- 每个固定的 m 给出一个关于 (q₁, q₂, k) 的线性约束，所以最大 P1 次解是 LP。
- 停时 τ 取首个到达 π 的角：此前沿轨道 γw 的下降不超过已产生的超出量；τ 时由面条件得 γw ≤ 0（剩余超出量 ≥ 0）。
- k ≥ 0 保证 w(1,1,σ(0)) ≥ w(1,1,σ_top)。
- 令 ε′ → 0 得：若 ε < γ·w(1,1,σ_top)，则 V_∞(W, ε) ≥ Λ₀。

为什么不用常数 ν（S1）：对偶函数 L(ν) ≤ min(L_sym(ν), 0.649 − 0.1ν)。L_sym 由对称策略的一维积分精确算出，0.649 是 LP 找到的零超出叠放策略的质量。两者的最大值约 0.497 < 0.5。在三维表述里，质量预算是 σ ≥ 0 的状态约束，叠放策略不可行，也就不进入 HJB 的比较。



# Cap-to-Robin reduction

## 4. 约化引理 R：把帽换成 Robin（作者级）

**一维常数。**
- σ[c] := inf{∫₀^∞ (G′² + π²G²/c²) dy : G(0) = 1}。
- σ₁ := inf{σ[c] : ∫₀^∞ c ≤ 1}。
- 伸缩关系：∫c ≤ α 时，inf σ = σ₁/√α。
- 数值（`t5_sigma1.py`，SLSQP，600 格）：σ₁ ≈ **2.0208**。最优帽是"蘑菇"形，c(0) = 2.69。常数剖面给出的上界是 2.3222。

**引理 R。** 设 λ₁(S_c) ≤ Λ，m′ = ∫₀^τ c，α′ = a − m′，σ := σ₁/√α′，ν := κ/(2α′)，σ′ := σ(1 − Λ/ν)。则 λ_red(D; σ′) ≤ Λ，其中
  λ_red(D; σ′) := inf{ [∫_D |∇w|² + σ′∫_{Γ₊∪Γ₋} w²] / ∫_D w² : w ∈ H¹(D)，w 在 ∂D ∩ {|y| < τ} 上为 0 }。

*证明。*
1. **帽内横切片。** 取 v ∈ H¹(C₊)，它在 ∂C₊ ∖ Γ₊ 上为 0，在 Γ₊ 上的迹为 g。
   - 对 a.e. y > τ，v(·, y) ∈ H¹₀(−c(y)/2, c(y)/2)。记 G(y) = ‖v(·, y)‖_{L²}，则 ∫|∂_x v|² dx ≥ π²G²/c²。
   - G 绝对连续，|G′| ≤ ‖∂_y v(·, y)‖，G(τ⁺) = ‖g‖。
   - 故 ∫_{C₊}|∇v|² ≥ ‖g‖²·σ[c|_{(τ,∞)}] ≥ σ‖g‖²。
2. **帽内质量。** 把 v 关于 y = τ 偶反射，得到面积 2|C₊| ≤ 2α′ 的开集上的 H¹₀ 函数。由 FK，∫_{C₊}v² ≤ ν⁻¹∫_{C₊}|∇v|²。
3. **合并。** 取基态 u。记 I = ∫_D|∇u|²，M = ∫_D u²，E 为两帽能量，m_C 为两帽质量，G 为两窗迹的 L² 范数平方和。
   - λ = (I + E)/(M + m_C)，m_C ≤ E/ν，E ≥ σG。
   - 若 λ ≤ Λ < ν（ν ≈ 263），则 λM ≥ I + E(1 − λ/ν) ≥ I + σ′G。
   - 所以 λ_red(D; σ′) ≤ Q(u|_D) ≤ λ ≤ Λ。∎

**推论。** (A) ⟸ (A_red)：对一切 m′ ≤ m，inf{λ_red(D; σ′(m′)) : D ⊂ 带，x-Steiner，y 对称，|D| ≤ 2m′} > Λ。
- 参数：m′ = 0.225 时 σ = 10.880，ν = 263.3，σ′ = 9.322。

**数值（`t4_reduced.py`，FD 罚函数，帽质量用 σ/ν 修正式，与 σ′ 式等价到 O(1%)）：**

| (τ, m′, a) | h | λ_red 最小 | 同网格圆盘（Dirichlet） | 精确圆盘 | 校准后 |
|---|---|---|---|---|---|
| (0.42, 0.225, 0.2595) | 0.01 | **39.305**（贴墙，c(τ) = 0.282） | 39.620 | 40.374 | ≈ 40.05 |
| (0.42, 0.225, 0.2595) | 0.007 | 39.612 | 39.824 | 40.374 | ≈ 40.16（+6.5%） |

| (0.45, 0.23, 0.2595) | 0.01 | 38.574 | 38.807 | 39.497 | ≈ 39.26（+4.1%） |

- λ_red 关于 m′ 递减，最坏情形在 m′ = m。
- 约化相对原问题只损约 0.8%：同网格 39.31 对 39.62。

- **引理 S（解析稿，解析稿 复核）。** 条带内 y 向对称递减重排（等价于我的圆周帽对称化）加 x-Steiner，得到双单调的 v。商不增，窗口迹变成 min_y。
- 所以只需证：对一切双 Steiner D ⊂ S_τ，|D| ≤ A₀，以及其上一切非负双单调 v（侧边为 0），Q(v) ≥ Λ‖v‖²。

## 2. 引理 G 与引理 T（作者级）

**arc 函数。** arc(L, A) 表示弦长 L、与弦围成面积 A 的圆弧长（A ≤ πL²/8，即不超过半圆）。
- 参数式：A = (L/2)²(φ − sinφ cosφ)/sin²φ，arc = Lφ/sinφ，φ ∈ (0, π/2]。
- d arc/dA = 1/R ≤ 2/L，其中 R 是圆弧半径。

**引理 G（碰窗口水平集的周长）。** 设 U ⊂ S_τ 是双 Steiner 开集，|U| = s，U ∩ {y = ±τ} = (−ℓ/2, ℓ/2)（ℓ > 0），U ⊃ R_ℓ := (−ℓ/2, ℓ/2) × (−τ, τ)，且 (s − 2τℓ)/2 ≤ πτ²/2。则
  Per(U; S_τ) ≥ max{ 2·arc(2τ, (s − 2τℓ)/2), √(4πs) − 2ℓ }。
*证明。*
- 第二项：Per(U) ≥ √(4πs)，且两面墙上的边界恰为两段长 ℓ 的线段。
- 第一项：V := U ∩ {x > ℓ/2}，面积 A = (s − 2τℓ)/2。
  - 从 (ℓ/2, τ) 沿 x = ℓ/2 下到 V 的迹的上端，再沿 ∂V ∩ {x > ℓ/2}，最后沿 x = ℓ/2 下到 (ℓ/2, −τ)，得到一条曲线 γ。
  - |γ| 恰好等于 U 在 {x ≥ ℓ/2} ∩ S_τ 中的相对周长：竖直段是 R_ℓ 与外部的分界。
  - γ 与弦 {ℓ/2} × [−τ, τ] 围成面积 A，γ 位于弦的一侧。由定弦 Dido 不等式，|γ| ≥ arc(2τ, A)。左侧同理。∎
- 注：
  - 由 arc(L, A) − arc(L, A − τℓ) ≤ τℓ·(2/L) = ℓ，第一项 ≥ P_lens(2τ, s) − 2ℓ。所以引理 G 严格强于 解析稿 引理 W 的"透镜 − 2w"。
  - τ = 0.45 时，A ≤ m′ ≤ 0.2282 < πτ²/2 = 0.318，条件自动满足。

**引理 T（能量型窗口 Talenti）。** 设 D 双 Steiner，|D| ≤ A₀，窗口宽 w；v ≥ 0 双单调，在 ∂D ∖ 窗口上为 0。记：
- v* 为递减重排（自变量 s 是面积）；
- ℓ_t := |{x : v(x, τ) > t}|，ℓ(s) := ℓ_{v*(s)}，它不减，且 0 ≤ ℓ ≤ w、2τℓ(s) ≤ s。

则
  ∫_D|∇v|² + σ′∫_{两窗}v² ≥ ∫₀^{A₀} P(ℓ(s), s)² (v*′)² ds + 2σ′∫₀^{A₀} (v*)² dℓ(s)，‖v‖² = ∫₀^{A₀}(v*)² ds。
*证明。*
1. 双单调性给出 v(x, y) ≥ v(x, τ)。所以水平集 U_t ⊃ R_{ℓ_t}，U_t 与墙相交恰为 (−ℓ_t/2, ℓ_t/2)，并且 U_t 本身双 Steiner。
2. 由引理 G（ℓ_t = 0 时用等周不等式），Per(U_t; S_τ) ≥ P(ℓ_t, |U_t|)。
3. 带轮廓的 Pólya–Szegő（余面积 + Cauchy–Schwarz）。v 零延拓过侧边后，{v = t} ∩ D 就是 U_t 在条带内的约化边界：
   ∫_D|∇v|² ≥ ∫₀^{|D|} P(ℓ(s), s)² (v*′(s))² ds。
4. 窗口项。单面墙上：∫v(x,τ)² dx = ∫₀^∞ 2t ℓ_t dt = −∫₀^∞ t² dℓ_t = ∫₀^{A₀} (v*(s))² dℓ(s)。
   - 第二步是分部积分：t → ∞ 时 ℓ_t = 0，t → 0 时 t²ℓ_t → 0。
   - 第三步换到 s 参数：t = v*(s)，ℓ 随 s 增加。
   - 两面墙乘 2。
5. q := v* 在 s ≥ |D| 时为 0，可以把区间延到 A₀（Dirichlet 端单调）。∎

**推论 T。** 若对每条可容许路径 ℓ(·)，形式 F_ℓ(q) := ∫₀^{A₀} P²q′² ds + 2σ′∫q² dℓ − Λ∫q² ds 在 {q ∈ H¹ : q(A₀) = 0} 上都 ≥ 0，则 λ_red(D) ≥ Λ 对一切窗口宽 ≤ w 的 D 成立。记 T(w) 为使之成立的最大 Λ，它关于 w 单调减。

**动态规划（数值）。**
- 固定 ℓ 时，Riccati 变量 r = P²q′/q 满足 r′ = −λ − r²/P²，r(0) = 0（自然端，P(0) = 0），ℓ 增加 dℓ 时 r 跳 +2σ′dℓ。
- 流对 r 保序：r ≤ 0 时 −r²/P² 关于 r 增。所以"(s, ℓ) 处的最小可达 r"满足标量 DP。λ ≤ T(w) 等价于 DP 在 [0, A₀) 上不爆破。
- 程序：`s6_energyDP.py`。w = 0 自检给 39.818，精确 FK 值为 39.808。

**常数 (T) 的证书设计（作者级）。**
- 找 (s, ℓ) 区域 {0 ≤ s ≤ A₀，0 ≤ ℓ ≤ min(w*, s/(2τ))} 上的有界 Lipschitz 函数 ρ，使得：
  - (a) ρ(0, 0) ≤ 0；
  - (b) ρ_s ≤ −Λ − ρ²/P(ℓ, s)²；
  - (c) ρ_ℓ ≤ 2σ′。
- 则对任意可容许路径，沿路径有 F_ℓ(q) ≥ ∫P²(q′ − ρq/P²)² + ∫[(−ρ_s − Λ − ρ²/P²) + (2σ′ − ρ_ℓ)ℓ′]q² − ρ(0,0)q(0)² ≥ 0（Picone，测度形式；跳跃同样成立）。
- 实现：取 DP 的最小可达 r 下移一点作为节点值，用 P1 插值；逐格用 arb 检查 (b)(c)。
- s = 0 附近用径向解 ρ = 4πs·(d/ds)log J₀(√(Λs/π))。
- 余量 0.67% 要求 s 方向约 10⁴ 格、ℓ 方向约 10² 格，单核分钟级。

**常数 (S) 的证书设计（作者级）。**
- Riccati r = f′/f 满足 r′ = π²/c² − Λ − r²，r(0) = 0。终端条件 r(τ) + σ′ ≥ 0 等价于形式非负。
- 找 (y, b) 上的障碍函数 ρ，b 为剩余预算，满足：
  - ρ(0, m′) ≤ 0；
  - ρ_y ≤ min_{c ≥ w*}[π²/c² + cρ_b] − Λ − ρ²（右端有闭式）；
  - ρ(τ, ·) ≥ −σ′。
- 这与 constB 的"预算为状态"同型，可直接改用其 LP + 逐格证书管线。

**m′ 的覆盖。**
- T 关于 A₀ 减、关于 σ′ 增；S 关于预算减、关于 σ′ 增；σ′ 关于 m′ 增。
- 所以 m′ ∈ [m₁, m₂] 时取 (A₀, σ′) = (2m₂, σ′(m₁)) 得下界。
- 浮点：m′ ≤ 0.22 时余量 ≥ 5%，只需在 [0.22, m] 上细分。



# S staircase criterion

### 3.1 问题
- 要证的命题：对一切可测 c ≥ w、∫₀^τ c ≤ m_hi、σ′ ≥ σ′(m_lo)，有
  μ_h[c] = inf {∫₀^τ (F′² + π²F²/c²) + σ′F(τ)²} / ∫₀^τ F² > Λ₀ = 37.7。0 端为 Neumann。
- 由横切片，λ_red ≥ μ_h[c(|·|)]。**不用 c 的单调性**：类变大只会让下确界变小。
- 由 1D Pólya–Szegő 加反向 Hardy–Littlewood，单调性其实不改变值，但这里不需要。

### 3.2 化为最优控制（作者级）
- **Prüfer 角。** F″ = (π²/c² − Λ₀)F，F(0) = 1，F′(0) = 0，(F, F′) = r(sin θ, cos θ)。
  则 θ′ = f(θ, c) = 1 + s(Λ₀ − 1 − π²/c²)，s = sin²θ，θ(0) = π/2。
- **等价判据。** μ_h ≤ Λ₀ ⟺ θ 到 π（F 有零点），或 θ(τ) ≥ θ_R := π/2 + arctan σ′（此时 F > 0，−F′/F(τ) ≥ σ′）。
  - 证明：F > 0 时有 Q(φ) = ∫F²((φ/F)′)² + (σ′ − q(τ))φ(τ)²，其中 q = −F′/F = −cot θ。
  - θ 越过 π 后不再回到 π 以下，因为在 θ = π 处 θ′ = 1。
  - 用 θ_R 的下界只会扩大可行集，所以是保守的。
- **势函数引理。** 设 Φ 是 θ 的分片线性函数，在每格上 Φ′ = −p。若在区间 J 的每格上
  g_ν(θ, p) := min_{c≥w} [c − ν − p·f(θ, c)] ≥ 0，
  则对任何留在 J 内的轨道段有 ∫c ≥ ν·(时长) + Φ(起点) − Φ(终点)。
  - 证明：Φ∘θ 绝对连续。格内部由 g ≥ 0 直接得到。
  - θ 停在格点上的正测度时间内 θ′ = 0，即 c = c₀(θ)；g ≥ 0 在格点处给出 c₀ − ν ≥ 0。
- **g 的闭式与无松弛的格上检查。**
  - g_ν(θ, p) = G(p, s) := m(p, s) − ν − p(1 + (Λ₀ − 1)s)，其中 m(p, s) = min_{c≥w}(c + pπ²s/c²)。
  - m 的闭式：(2K)^{1/3} ≤ w 时为 w + K/w²，否则为 (3/2)(2K)^{1/3}（K = pπ²s）。后者在任何情形都是下界。
  - **G 关于 s 是凹的**（仿射函数的 min），而 s 在每格上单调，所以格上最小值是两端点值的较小者，没有松弛。
  - 第一版用 s_lo/s_hi 交叉松弛，损失一阶的 3e−4，在最紧处失败；这一改动是关键。

### 3.3 阶梯论证（作者级）
- 记 θ* 为 c = w 时 f = 0 的平衡点（接近 π 的那个）。取层 θ_R = t₀ < t₁ < … < t_K ≈ θ*，底 θ_b = 0.25。
- 对一条可行轨道（θ(0) = π/2，c ≥ w，可行即 θ(τ) ≥ θ_R 或到达 π），按其 min θ 和 max θ 分情形：
  - **跌破**（min θ < θ_b）：跌破之后必须重新到达 θ_R。用 ν = w 的势，得
    质量 ≥ wτ + ∫_{θ_b}^{θ_R} p_max(·; w)。
  - **顶层**（max θ ≥ t_K）：质量 ≥ A_K。
  - **第 k 层**（max θ ∈ [t_k, t_{k+1})，min θ ≥ θ_b）：质量 ≥ max(A_k, B_k)，其中
    - A_k = wτ + ∫_{π/2}^{t_k} p_max(·; w)：首达 t_k 前用 ν = w 的势；
    - B_k = ν_kτ + ∫_{π/2}^{t_k} p_max(·; ν_k) − ∫_{θ_R}^{t_k} p_min(·; ν_k)，ν_k ≲ c₀(t_{k+1})。
    - B_k 的推导：首达 t_k 之前用势 Φ₁（斜率 p_max(ν_k)），之后用势 Φ₂（斜率 p_min(ν_k)）。两段都用时间奖励 ν_k，相加后与首达时刻 T_k 无关。
    - 允许 ν_k > w，是因为轨道全程低于 t_{k+1}，那里"停住"的代价 c₀ ≥ ν_k。证书逐格检查可行区间 [p_min, p_max] 非空，范围是 [θ_b, t_{k+1}] 的每一格。
- **结论：** 最小质量 ≥ min(跌破, A_K, min_k max(A_k, B_k))。
- **直观解释：** 最优轨道先爬到 θ* 附近，再以 c = w 在不稳定平衡点旁"免费等待"。阶梯在"爬多高"和"在多高处等"之间取最坏情形。
  只用 θ_R 的时间无关松弛（TF）恰好丢掉了这部分代价。
