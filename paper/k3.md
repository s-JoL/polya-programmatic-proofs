## 0. 主定理、经典工具与总览

**主定理。** 设 Ω ⊂ ℝ² 为开集，0 < |Ω| < ∞（可以无界、有任意多个孔、不连通）。λ₃(Ω) 为 Dirichlet 拉普拉斯的第三特征值（按重数计）。则 **|Ω|·λ₃(Ω) > 12π**。

**推论（题目类）。** 设 P 的外边界是有理顶点简单多边形，内有有限个严格内含、互不相交的多边形孔，全部边界取 Dirichlet 条件。则 |P|λ₃(P) > 12π。

## 1. 预备；环 1：括号与定理 B

### 1.0 记号与基本事实
- **离散谱。** |Ω| < ∞ 时，H¹₀(Ω) 零延拓进 H¹(ℝ²)，嵌入 L²(Ω) 是紧的（经典 7）。所以谱离散：0 < λ₁ ≤ λ₂ ≤ … → ∞。不需要有界性，也不需要边界正则性。
- **伸缩。** λ_k(tΩ) = t⁻²λ_k(Ω)，|tΩ| = t²|Ω|。**以下设 |Ω| = 1，目标是 λ₃ > Λ = 12π。**
- **直线与剖面。** 直线 L 取为 x 轴，R 为关于 L 的反射。Ω± := Ω ∩ {±y > 0}。c±(t) := H¹(Ω ∩ {y = ±t})（t > 0），由 Tonelli 可测，且 ∫₀^∞ c± = |Ω±|。
- **加倍集。** S± := Ω± ∪ R(Ω±) ∪ (Ω ∩ L) 是开集。λ_k^{ev}(S±) 是 H¹₀(S±) 中关于 L 为偶的子空间上的 min-max 值。
- **一维量。** 对可测的 c : ℝ → [0, ∞]：
  - μ[c] := inf{ ∫(F′² + π²F²/c²)/∫F² : F ∈ H¹(ℝ)，F 在 {c = 0} 上 a.e. 为 0 }；
  - V[c] := inf{ max(μ[c₁], μ[c₂]) : c₁, c₂ ≥ 0 可测且为偶函数，c₁ + c₂ ≤ c(|·|) }；
  - 对偶函数 c，μ 等于半直线上"0 处 Neumann"的谱底。
- **Steiner 型集合。** 对偶函数 c ≥ 0，令 S_c := {(x, y) : |x| < c(y)/2}。若 c 下半连续，S_c 是开集，且 |S_c| = ∫c。

### 命题 1.1（Neumann 括号）
**陈述。** 对任意直线 L，λ₃(Ω) ≥ min(λ₂^{ev}(S₊), λ₂^{ev}(S₋))。

**证明要点。**
1. 令 V± 为 {u|_{Ω±} : u ∈ C_c^∞(Ω)} 在 H¹(Ω±) 中的闭包。限制映射 H¹₀(Ω) → V₊ ⊕ V₋ 是单射，并且保持 Dirichlet 形式与 L² 范数（L 是零测集）。
2. 由 min-max（经典 6），λ₃(Ω) ≥ min(ν₂(V₊), ν₂(V₋))：三个最小值里必有两个来自同一侧。
3. 偶反射 u ↦ u(x, |y|) 把 V₊ 等距地（差一个常数因子）嵌入 H¹₀(S₊) 的偶子空间，所以 ν₂(V₊) ≥ λ₂^{ev}(S₊)。若 Ω₊ = ∅，约定 ν = +∞。∎

### 命题 1.2（坏侧的两个核）
**陈述。** 若 λ₂^{ev}(S₊) < ∞，则存在开集 W₁, W₂ ⊂ S₊，满足：
- 两者不交，都关于 L 对称；
- λ₁(W_i) ≤ λ₂^{ev}(S₊)；
- 对每个 y（含 y = 0），W₁^y ⊔ W₂^y ⊂ S₊^y，其中 S₊^y 是 Ω 在高度 |y| 处的截线（y < 0 时取镜像；y = 0 时是 Ω ∩ L）。

**证明要点。**
- **正则性。** 偶的极小极大本征函数也是 S₊ 上真正的 Dirichlet 本征函数：对奇试探函数，弱形式两边都为 0。由 Weyl 引理（经典 8），它在 S₊ 内光滑。
- **Hedberg 型引理。** 若 u ∈ H¹₀(U) ∩ C(U)，则 u⁺ ∈ H¹₀({u > 0})。证明：取 u_n ∈ C_c^∞(U) 使 u_n → u。v_n := min(u_n⁺, (u − ε)⁺) 的支集是 {u > 0} 的紧子集，且 v_n ⇀ (u − ε)⁺。由 H¹₀ 的弱闭性，(u − ε)⁺ ∈ H¹₀({u > 0})，再令 ε → 0。
  由此，若 φ 是 λ 本征函数，用 φ^± 作试探函数，得 λ₁({±φ > 0}) ≤ λ。
- **情形 (i)：λ₁^{ev} < λ₂^{ev}。**
  - λ₁^{ev} 单重。|η₁| 也是极小元，所以 η₁ 不变号，可取 η₁ ≥ 0。
  - 取 η₂ ⊥ η₁ 为 λ₂^{ev} 本征函数。若 η₂ 变号，令 W₁ = {η₂ > 0}，W₂ = {η₂ < 0}。
  - 若 η₂ 不变号，可设 η₂ ≥ 0。这时 η₁, η₂ ≥ 0、连续，且 ∫η₁η₂ = 0，所以 {η₁ > 0} ∩ {η₂ > 0} = ∅（否则乘积在一个非空开集上为正）。令 W_i = {η_i > 0}，λ₁(W₁) ≤ λ₁^{ev} ≤ λ₂^{ev}。
- **情形 (ii)：λ₁^{ev} = λ₂^{ev}。**
  - 本征空间 E 的维数 ≥ 2，且 φ ∈ E 推出 |φ| ∈ E（|φ| 也是极小元）。取 φ₁ = |φ| ≥ 0，再取 φ₂ ∈ E 与 φ₁ 正交。
  - 若 φ₂ 变号，则 φ₂^± = (|φ₂| ± φ₂)/2 ∈ E，令 W₁ = {φ₂ > 0}，W₂ = {φ₂ < 0}。
  - 若 φ₂ 不变号，同上，令 W_i = {φ_i > 0}，它们不交。
- **对称性与纤维。** 所用本征函数都是偶函数，所以 W_i = R(W_i)。纤维关系由 S₊^y 的定义直接得到。∎

### 定理 1.3（定理 B，无归一化形式）
**陈述。** λ₂^{ev}(S₊) ≥ V[c₊]，从而 λ₃(Ω) ≥ min(V[c₊], V[c₋])。

**证明要点。**
- 取命题 1.2 的核，令 c_i(y) := |W_i^y|。c_i 是偶函数，且 c₁ + c₂ ≤ c₊(|·|) 逐点成立。
- **切片 Poincaré。** 设 u ∈ C_c^∞(W)。W^y 是若干开区间之并，每个区间长 ≤ c(y)，所以 ∫u_x²dx ≥ (π/c(y))²∫u²dx。F(y) = ‖u(·, y)‖₂ 是 Lipschitz 函数，且 |F′| ≤ ‖u_y(·, y)‖。所以 λ₁(W) ≥ μ[c_W]。
- 于是 V[c₊] ≤ max μ[c_i] ≤ max λ₁(W_i) ≤ λ₂^{ev}(S₊)。∎

## 2. 环 2：Steiner 核、引理 L1₂、选线

### 引理 2.2（Steiner 核与半质量界）
**陈述。** 设 |Ω| = 1，L 是平分线，且 λ₂^{ev}(S₊) ≤ Λ。取命题 1.2 的核，令 c_i(y) := H¹(W_i^y)。则：
- (i) c_i 是偶函数且下半连续，S_{c_i} 是开集；
- (ii) λ₁(S_{c_i}) ≤ λ₁(W_i) ≤ Λ；
- (iii) κ/(2Λ) ≤ a_i := ∫₀^∞ c_i ≤ 1/2 − κ/(2Λ) = 0.2590339 < a。

**证明要点。**
- (i) 由 Fatou 引理（W_i 是开集）。
- (ii) 取 u ∈ C_c^∞(W)，K = supp u。K* := {|x| ≤ |K^y|/2} 是紧集且含于 S_c。|u|* 是 Lipschitz 函数、支集在 K* 内，所以 |u|* ∈ H¹₀(S_c)。再用经典 2。
- (iii) 由 FK，|W_i| ≥ κ/Λ，且 a_i = |W_i|/2。W₁、W₂ 的上半部分不交，都含于 Ω₊，所以 a₁ + a₂ ≤ 1/2。∎

### 常数 (A)（定理 4.12）
**陈述。** 对一切偶、下半连续的 c ≥ 0，若 ∫₀^τ c ≤ m 且 ∫₀^∞ c ≤ a，则 **λ₁(S_c) > 12π**。

### 引理 2.3（L1₂）
**陈述。** 设 L 是平分线，且 λ₂^{ev}(S₊) ≤ Λ。则 q₊ := |Ω ∩ {0 < y < τ}| > 2m。

**证明。** c_i 满足常数 (A) 的其余条件。若 ∫₀^τ c_i ≤ m，则由常数 (A)，λ₁(S_{c_i}) > Λ，与引理 2.2(ii) 矛盾。所以两个核都有 ∫₀^τ c_i > m，于是 q₊ ≥ ∫₀^τ(c₁ + c₂) > 2m。
**这里只用到常数 (A) 的"> Λ"。** ∎

### 引理 2.4（空隙情形）
**陈述。** 若某方向 n 的面积中位数集是非退化区间 [s₁, s₂]，则对 s ∈ (s₁, s₂)，直线 L = {x·n = s} 两侧都有 λ₂^{ev}(S±) > Λ。

**证明。**
- 条带 {s₁ < x·n < s₂} 与 Ω 的交是零测集，而 Ω 是开集，所以两者不交。于是 S₊ = Ω₊ ⊔ R(Ω₊)，两部分的距离为正。
- 设 λ₂^{ev}(S₊) ≤ Λ。每个核 W_i 的上半块 W_i⁺ 满足 λ₁(W_i⁺) = λ₁(W_i) ≤ Λ，由 FK 得 |W_i⁺| ≥ κ/Λ。
- 于是 |W₁⁺| + |W₂⁺| ≥ 2κ/Λ = 0.9639 > 1/2 = |Ω₊|，矛盾。∎

### 常数 (B)（定理 3.1）
**陈述。** 对一切 ε < 0.0879293，V_∞(0.9, ε) ≥ 37.7，其中 V_∞(W, ε) := inf{ V[c] : ∫₀^∞ c ≤ 1/2，∫₀^∞(c − W)₊ ≤ ε }。

### 引理 2.6（分支 B：垂线剖面）
**陈述。** 设 |Ω ∩ {|y| < τ}| > 4m，L₁ 是法向为 (1, 0) 的平分线。则 L₁ 两侧都有 λ₂^{ev} > Λ。

**证明。**
- 竖线 {x = x₀} 上的截线长 ≤ 2τ + e(x₀)，其中 e(x₀) := H¹(Ω ∩ {x = x₀} ∩ {|y| ≥ τ})，且 ∫e = 条带外质量 < 1 − 4m。
- 所以每一侧的剖面 c 都满足 ∫₀^∞ c = 1/2 与 ∫₀^∞(c − 0.9)₊ < 0.0872 < 0.0879293。
- 由常数 (B) 与定理 1.3，λ₂^{ev} ≥ V[c] ≥ 37.7 > Λ。∎

### 定理 2.5（选线）
**陈述。** 对任意开集 Ω ⊂ ℝ²，|Ω| = 1，存在直线 L，使 λ₂^{ev}(S±) > Λ。

**证明。**
0. 若某方向的面积中位数不唯一，用引理 2.4。以下设所有方向的中位数都唯一。
1. **连续性。** F(n, s) := |Ω ∩ {x·n < s}| 关于 (n, s) 联合连续：先取 R 使 |Ω ∖ B_R| 很小，再估计 B_R 内的部分。由中位数唯一，s(n) 连续。
   于是 q(n) := |Ω ∩ {s(n) < x·n < s(n) + τ}| 连续，且 q(−n) 是另一侧的条带质量。这里只用到有限测度。
2. **零点。** φ(n) := q(n) − q(−n) 在 S¹ 上是连续的奇函数，有零点 n₀。记 Q₀ := q(n₀)。论证对任意零点都成立。
3. **分支 A：Q₀ ≤ 2m。** 由引理 2.3 的逆否命题，L_{n₀} 两侧都好。
4. **分支 B：Q₀ > 2m。** 两侧条带质量之和 2Q₀ > 4m，由引理 2.6，垂直平分线两侧都好。∎

## 3. 环 3：常数 (B)

### 定理 3.1（计算机辅助；解析判据与精确证书）
**陈述。** 取 Λ₀ = 37.7。若偶剖面对 (c₁, c₂) 满足 max μ[c_i] < Λ₀ 且 ∫₀^∞(c₁ + c₂) ≤ 1/2，则 ∫₀^∞(c₁ + c₂ − 0.9)₊ ≥ ε_cert = 0.0879293473…。
**推论。** 对 ε < ε_cert，V_∞(0.9, ε) ≥ 37.7。理由：若 c₁ + c₂ ≤ c，则剖面对的质量与超出量都只会更小。

**证明要点。**
- **化为最优控制。** 先半直线化；再把 c 截断到 [0, X] 并加 ε′（μ 关于 X 的收敛来自紧支试探函数的稠密性），最后令 ε′ → 0。
- **Prüfer 角。** 记 t = √Λ₀·y，ℓ_i = √Λ₀·c_i。Prüfer 角满足 θ_i′ = 1 − π²sin²θ_i/ℓ_i²，θ_i(0) = π/2。由半直线振荡定理（经典 9），μ < Λ₀ ⟺ θ_i 在有限时间内到达 π。
- **松弛质量变量。** σ := (Λ₀/c)(预算 − 已用质量) − U₁ − U₂，其中 U_i = 1 + cos θ_i，c = 3√3π/2。由单角不等式 ℓ ≥ cXθ′，σ 单调不增。在首达时刻，σ ≥ 0。所以可行轨道停在盒子 [0,2]² × [0, σ_top] 内。
- **HJB 次解判据。** 在每个闭四面体上要求 (G) k ≥ 0、P_i ≥ 0，以及 (H) 3ΣP_iX_i ≤ Ψ_k(ΣP_i^{1/3}X_i)；并要求面上 w ≤ 0。则超出量 ≥ γ·w(1, 1, σ_top)。
- **证书。** 次解由 LP 加割平面求出；然后在 8664 个四面体上逐个做 arb 检查，另有一份精确有理数检查。

## 4. 环 4：常数 (A)

### 4.1 设定
- c ≥ 0 为偶函数、下半连续，∫₀^∞ c ≤ a，m′ := ∫₀^τ c ∈ [0, m]。用反证法，设 λ := λ₁(S_c) ≤ Λ = 12π。
- 记条带 T := ℝ × (−τ, τ)，条带部分 D := S_c ∩ T，两个帽 C± := S_c ∩ {±y > τ}，α′ := a − m′。c 是偶函数，所以每个帽的面积都等于 ∫_τ^∞ c ≤ α′。
- 基态存在：|S_c| ≤ 2a，紧嵌入（经典 7）。

### 引理 4.2（颈部 Talenti，m′ ≤ 0.03）
**陈述。** 若 ∫₀^τ c ≤ 0.03（τ = 0.45）且 ∫₀^∞ c ≤ a，则 λ₁(S_c) ≥ 45.8318 > Λ。

**证明要点。**
- **只需看对称分支。** S_c 的连通分支一一对应于 {c > 0} 的分量区间 J。
  - J ∌ 0 的分支含于某个半平面，面积 ≤ a，所以 λ₁ ≥ κ/a = 70.01。
  - J ∋ 0 的分支只有一个，它关于 y 对称；其上基态单重，因而为偶函数 u。
- **轮廓。** 记 U_t = {u > t}，|U_t| = s。
  - 由均值论证，可在一个正测度的好切片集中取 y_t ∈ (0, τ)，使 H¹(U_t ∩ {y = y_t}) ≤ m₀/τ。
  - 由 BV 切片（经典 5），Per(U_t) ≥ 2Per(U⁺) − 2m₀/τ；又 |U⁺| ≥ s/2 − m₀。
  - 所以 Per(U_t) ≥ I(s) := max(√(4πs), 2[√(4π(s/2 − m₀)₊) − m₀/τ])。
- **一维问题。** 由带轮廓的 PS（经典 4），λ₁ ≥ inf ∫₀^{2a}I²g′²/∫₀^{2a}g²（g(2a) = 0）。端点取 2a 是因为 |S_c| ≤ 2a；区间 [0, |K|] 上的函数零延拓到 [0, 2a]，商不变。
- **证书 N。** 构造 Riccati 超解 ζ′ ≥ λ + ζ²/I²，ζ(0) = 0，在 [0, 2a] 上有限。起步段 s ≤ 2m₀ 用 Bessel 精确解（在 s < κ/λ = 0.396 之前没有极点），之后每格用闭式 tan 解，允许向上跳。由 Picone 恒等式 ∫I²g′² − λ∫g² = ∫I²(g′ + ζg/I²)² + ∫(ζ′ − ζ²/I² − λ)g² − [ζg²] ≥ 0。∎



### 引理 4.3（σ₁ 闭式，定理）
**陈述。** 令 σ[c] := inf{ ∫₀^∞(G′² + π²G²/c²) : G(0) = 1 }，σ₁ := inf_{∫c ≤ 1} σ[c]。则 σ₁ = (3/2)(π/√3)^{1/2} = 2.0201605306…；且 ∫c ≤ α 时 inf σ = σ₁/√α。

**证明。**
- 伸缩：c ↦ √α·c(·/√α)。
- 记 B = ∫G^{2/3}。由 Hölder，∫G²/c² ≥ B³。由 1 ≤ (4/3)(∫G′²)^{1/2}B^{1/2}，得 ∫G′² ≥ 9/(16B)。
- 对 B 取极小，min_B[9/(16B) + π²B³] = 3/(4B*)，B*⁴ = 3/(16π²)。
- 等号在 G = (1 − y/Y)^{3/2}、Y⁴ = 3/π² 时取到。∎

### 引理 4.4（R：帽换成墙上的 Robin，m′ ∈ [0.03, m]）
**定义。**
- 可容许类 𝒱(D) := { v ∈ H¹(T) : 在 T ∖ D 上 v = 0 a.e. }。
- Q_σ(v) := ∫_T|∇v|² + σ∫_{∂T}v²；λ_red(D; σ) := inf Q_σ(v)/‖v‖²。
- 对 Λ̃ ∈ {Λ, Λ₀}，令 σ′_{Λ̃}(m′) := σ₁α′^{−1/2}(1 − 2Λ̃α′/κ)。它关于 m′ 递增，在 m′ ≥ 0.03 时 ≥ 0.20056 > 0。

**陈述。** 若 λ ≤ Λ 且 m′ ∈ [0.03, m]，则对 Λ̃ = Λ 和 Λ̃ = Λ₀ 都有 λ_red(D; σ′_{Λ̃}(m′)) ≤ λ。

**证明要点。** 取基态 u ∈ H¹₀(S_c)。它零延拓后在 H¹(ℝ²) 中，所以 u|_T ∈ 𝒱(D)。
- **帽内横切片。** 对 a.e. y > τ，u(·, y) ∈ H¹₀(−c(y)/2, c(y)/2)。G(y) = ‖u(·, y)‖ 绝对连续，且 G → 0。由引理 4.3，帽能量 E± ≥ (σ₁/√α′)·‖迹‖²。
- **帽质量。** 把 u|_{C±} 关于墙偶反射，用 H¹ 版 FK（经典 1′），得 m_{C±} ≤ E±/ν，ν = κ/(2α′) ≥ 39.58 > Λ₀。
- **代数。** λM = I + E − λm_C ≥ I + E(1 − Λ̃/ν) ≥ I + σ′_{Λ̃}G。这里用到 λ ≤ Λ ≤ Λ̃ < ν。若 M = 0，则 λ ≥ ν，矛盾。∎

**说明。** 证书 (T) 用 σ′_{Λ₀}，证书 (S) 用 σ′_Λ。由本引理，两者都合法。但正因为 (S) 用的是 σ′_Λ，它要求反设 λ ≤ Λ，所以常数 (A) 只能写成 > 12π（见定理 4.12）。



### 引理 4.5（S：双 Steiner 化与双单调化）
**陈述。** 设 σ ≥ 0。则
  λ_red(D; σ) ≥ inf{ Q_σ(v)/‖v‖² : v ∈ 𝒱(D*)，v ≥ 0，v 关于 |x|、|y| 都不增 }，
其中：
- D* := {(x, y) : |y| < |D^x|/2} 是双 Steiner 集，|D*| = 2m′；
- D* ⊃ (−w*/2, w*/2) × (−τ, τ)，窗口宽 w* := ess inf_{|y|<τ} c，所以 2τw* ≤ 2m′；
- D* 的水平剖面 c* 满足 c* ≥ w*，且 ∫₀^τ c* = m′。

**证明要点。** 设 v ∈ 𝒱(D)。
0. **取绝对值。** 把 v 换成 |v|：能量不变，迹的平方不变，仍在 𝒱(D) 中。
1. **y 偶化。** v_e := √((v² + v(x, −y)²)/2) ∈ 𝒱(D)（D 关于 y 对称）。L² 范数与 Robin 项不变，能量不增。
2. **y 方向单调重排。** 在半带 ℝ × (0, τ) 上沿 y 做单调递减重排，再偶延拓（经典 3）。
   - 这是 H¹(T) 版本，墙上不要求为 0。区间上的一维单调重排不需要边界条件；重排逐纤维进行，所以可以局部化到 (−R, R) × (0, τ)，再令 R → ∞。
   - 墙上的迹变为 ess inf_y，所以 Robin 项不增；这一步要求 σ ≥ 0。
   - 支集落入 D*。
3. **x 方向 Steiner 对称化**（经典 2′）。
   - H¹(T) 版本：关于竖直线的极化只交换同一高度上的点，所以保持每个水平带上的能量。迭代极化在 L² 中收敛到 Steiner 对称化（Brock–Solynin），再用弱下半连续性，得到能量不增。
   - 迹与重排可交换：y ↦ v(·, y) ∈ C([−τ, τ]; L²)，且重排是 L² 非扩张的。所以 Robin 项不变。
   - 支集仍在 D*：D* 的水平截线是以 0 为中心的区间。
   - 重排保序，所以 y 方向的单调性保持。∎

**补充（迹的支撑）。** 双单调的 v ∈ 𝒱(D*) 在 |x| > w*/2 处的墙上迹为 0，因为那里的列不满。



### 4.6 情形 w* = 0（定理）
w* = 0 时，每个 x ≠ 0 都有 |D*^x| < 2τ，所以每个 v ∈ 𝒱(D*) 的墙上迹 ≡ 0，从而 v ∈ H¹₀(T)，且 v 在测度为 2m′ 的集合外为 0。由 H¹ 版 FK，Q/‖v‖² ≥ κ/(2m′) ≥ κ/(2m) = 39.8081 > 37.7。

若 ess inf_{|y|<τ} c > 0（即使 c 在个别点为 0），则 w* > 0，属于下面 (T) 或 (S) 的情形。

### 引理 4.6（G：碰窗口水平集的周长）
**陈述。** 设 U ⊂ T 是双 Steiner 开集，|U| = s，满列宽度恰为 ℓ > 0（所以 U ⊃ R_ℓ := (−ℓ/2, ℓ/2) × (−τ, τ)）。则
  Per(U; T) ≥ P(ℓ, s) := max{ 2·arc(2τ, (s − 2τℓ)/2), √(4πs) − 2ℓ }。

**证明要点。**
- **第二项。** Per(U; ℝ²) = Per(U; T) + 2ℓ（|x| > ℓ/2 处列不满，不触墙），再用等周不等式。
- **第一项。** 令 V = U ∩ {x > ℓ/2}，A = |V|。取弦左侧的优弓形 K，使 |V ∪ K| = πR²。由 BV 粘合（经典 5），Per(V ∪ K) = |γ| + |优弧|，其中 |γ| 包括弦上的两段竖直落差。由等周不等式，|γ| ≥ arc(2τ, A)。
- Per(U; T) = 2|γ|。本论证对一切 A > 0 都成立；证书中 arc 切线下界的凸性需要 A ≤ πτ²/2，而这里 A ≤ m′ < 0.318。∎



### 引理 4.7（T：能量型窗口 Talenti）
**陈述。** 设 D 双 Steiner，|D| ≤ A₀，窗口宽 ≤ w；v ∈ 𝒱(D) 非负、双单调。记：
- v* 为 v 关于面积 s 的递减重排；
- ℓ_t := |{x : v(x, τ) > t}|，ℓ(s) := ℓ_{v*(s)}。

则 ℓ(s) 不减，0 ≤ ℓ ≤ w，2τℓ(s) ≤ s，并且
  Q_σ(v) ≥ ∫₀^{A₀} P(ℓ(s), s)²(v*′)² ds + 2σ∫₀^{A₀}(v*)² dℓ(s)，‖v‖² = ∫₀^{A₀}(v*)² ds。

**证明要点。**
- **截断。** 先把 v 截断为有界函数 min(v, M)，再令 M → ∞；Q 与 ‖·‖ 都连续收敛。
- **水平集结构。** 若 v(x₀, τ) > t，则 U_t ⊃ (−|x₀|, |x₀|) × (−τ, τ)。所以 U_t 双 Steiner，满列宽度与 ℓ_t 只在可数个 t 处不同。这个方向不能省，因为 P 关于 ℓ 递减。
- **v* 局部绝对连续。** 由引理 4.6，双 Steiner 水平集的相对周长有正下界：有满列时 ≥ 4τ，无满列时 ≥ √(4πs)，所以 Per(U_t; T) ≥ min(√(4πs), 4τ) > 0。由 Brothers–Ziemer/Talenti 的论证（经典 4），v* 在 (0, A₀] 上局部绝对连续。
- **能量项。** 余面积公式加 Cauchy–Schwarz，再逐层使用引理 4.6。
- **窗口项。** 由层饼公式，每面墙上 ∫v(x, τ)²dx = ∫2tℓ_t dt = ∫(v*)² dℓ(s)，约定 ℓ(0⁻) = 0。迹分布的原子使 ℓ 在 v* 平台的右端跳跃。
- **端点。** v* 在 s ≥ |D| 时为 0。∎



### 判据 4.8 与证书 (T)
**函数类。** 𝒬 := { q : q 有界，在 (0, A₀] 上局部绝对连续，∫P̃²q′² < ∞，q(A₀) = 0 }。由引理 4.7，v* ∈ 𝒬。

**判据。** 在 {0 ≤ s ≤ A₀，0 ≤ ℓ ≤ w} 上取 P1 函数 ρ = K cot Θ（0 < Θ < π，K = 20）。若在每个闭三角形上满足：
- (a) ρ(0, 0) = 0；
- (b) ρ_s ≤ −Λ₀ − ρ²/P̃²；
- (c) ρ_ℓ ≤ 2σ；

则对一切不减路径 ℓ(·) 与一切 q ∈ 𝒬，都有 F_ℓ(q) := ∫P̃²q′² + 2σ∫q²dℓ − Λ₀∫q² ≥ 0。从而 Q_σ(v) ≥ Λ₀‖v‖²。

**推导。**
- g(s) := ρ(s, ℓ(s)) 是 BV 函数，满足测度不等式 dg ≤ −(Λ₀ + g²/P̃²)ds + 2σ dℓ。
- 逐点有 P̃²q′² ≥ 2gqq′ − g²q²/P̃²；分部积分 ∫2gqq′ = [gq²] − ∫q²dg。合起来 F ≥ −ρ(0,0)q(0)² ≥ 0。
- s = 0 端：先在 [ε, A₀] 上写恒等式，再令 ε → 0（ρ = O(s)，q 有界）。
- 单元上的 P̃ 下界：ℓ = 0 的边用 √(4πs)，ℓ > 0 的单元用 P(ℓ_{k+1}, s_i)，底行取两者的 min。首格用精确的 √(4πs) 加 |cos Θ| ≤ Θ_s·s。

**证书 (T)（严格数值）。**
- m′ ∈ [0.03, 0.2282] 分 9 个盒；每盒取 A₀ = 2m₂、σ = σ′_{Λ₀}(m₁) 的下界、w = min(0.241, m₂/τ)。
- 每盒 192000 个三角形，arb 逐个检查。
- 结论：对一切 m′ ∈ [0.03, 0.2282] 与 0 < w* ≤ 0.241，λ_red(D; σ′_{Λ₀}(m′)) ≥ 37.7。



### 引理 4.9（横切片）
**陈述。** 对双 Steiner 的 D*（剖面为 c*）与 v ∈ 𝒱(D*)，有 Q_σ(v)/‖v‖² ≥ μ_h[c*]，其中
  μ_h[c] := inf_f [∫₀^τ(f′² + π²f²/c²) + σf(τ)²]/∫₀^τ f²（0 处 Neumann，τ 处 Robin）。
这一步不需要 c* 单调。

**证明要点。**

### 判据 4.10–4.11 与证书 (S)
**判据 4.10（Prüfer）。** 令 F″ = (π²/c² − Λ₀)F，F(0) = 1，F′(0) = 0，(F, F′) = r(sin θ, cos θ)。则 θ′ = 1 + sin²θ·(Λ₀ − 1 − π²/c²)，θ(0) = π/2，并且
  μ_h[c] ≤ Λ₀ ⟺ θ(τ) ≥ θ_R := π/2 + arctan σ。

推导：
- 若 F 在 [0, τ] 上为正，基态代换给出 Q − Λ₀∫φ² = ∫F²((φ/F)′)² + (σ − q(τ))φ(τ)²，其中 q = −cot θ。下确界可以取到，所以另一侧是严格不等号。
- 若 F 有零点，θ 越过 π 后不会回落，因为在 θ = π 处 θ′ = 1。

**判据 4.11（势函数与阶梯）。**
- **势函数引理。** 若在闭格上 g_ν(θ, p) := min_{c ≥ w}[c − ν − p·f(θ, c)] ≥ 0，则 ∫c ≥ ν·时长 + Φ(起点) − Φ(终点)。θ 停在格点上的时刻集上 a.e. 有 θ′ = 0，c = c₀(节点)。
- **凹性。** g_ν 关于 s = sin²θ 是凹的。含真 π/2 的格用 s ∈ {min(s_a, s_b), 1}。
- **阶梯。** 按轨道分成跌破、顶层、第 k 层三类，情形完备。最小质量下界依次为 wτ + ∫p_max、A_K、max(A_k, B_k)。
